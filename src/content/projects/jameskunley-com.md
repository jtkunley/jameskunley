**Approach.** Built with Astro and statically generated, with zero client-side JavaScript. Blog posts and projects are Markdown files validated by typed content schemas, so adding content never means touching layout code.

**Deployment.** Every push to `main` builds and deploys to GitHub Pages through GitHub Actions, served on a custom domain over HTTPS.
